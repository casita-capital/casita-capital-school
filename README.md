# Casita Capital School

Weekly calendar and to-do list creator for school activities, homework, and weekly planning, hosted at `school.casitacapital.com`.

## Quick Links
- **Architecture & Supabase Guide**: See [`SUPABASE_INTEGRATION_GUIDE.md`](./SUPABASE_INTEGRATION_GUIDE.md) for full architecture, design system references, and database integration instructions under the `"school"` schema.

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3002](http://localhost:3002) in your browser.

3. **Run Typecheck Verification**:
   ```bash
   npm run typecheck
   ```
